# Calc2MC
This mod adds one very... interesting feature. Support to use your calculator as a controller for minecraft. It just needs this mod and a separate app running on your calculator to work, with instructions at the bottom of the page. Also a part of this mod are customisable keybinds for the calculator and support to move around menus and use your mouse so you never have to put down the calculator.

## Support & Compatibility
This mod only supports the [Texas Instruments TI 84 Plus CE](https://education.ti.com/eu/products/calculators/graphing-calculators/ti-84-plus-ce-t) & the [Texas Instruments TI‑84 Plus CE‑T Python Edition](https://education.ti.com/en/products/calculators/graphing-calculators/ti-84-plus-ce-python) calculators.

## Installation (**IMPORTANT**)

This mod requires a separate program running on your calculator in order to work properly.

### 1. Install Cesium / enable ASM programs

Before installing the calculator app, you’ll need to set up a shell such as Cesium on your calculator.

You can follow one of these tutorials:

* [arTIfiCE + Cesium installation guide](https://yvantt.github.io/arTIfiCE/)
* [Video tutorial for installing Cesium on the TI‑84 Plus CE](https://www.youtube.com/watch)

### 2. Install the Calc2MC calculator program

1. Download the latest [Calc2MC calculator files](https://github.com/BouncingElf10/Calc2MC/releases) from [here](https://github.com/BouncingElf10/Calc2MC/releases). (MCCTRL.8xp)
2. Connect your calculator to your computer using the USB cable.
3. Open [TI Connect CE](https://education.ti.com/en/products/computer-software/ti-connect-ce-sw)
4. Drag the Calc2MC files onto your calculator.
5. Launch the program through Cesium.

### 3. Install the Minecraft mod

1. Install the Minecraft mod like any normal Fabric/Forge mod.
3. Start the Calc2MC program on your calculator **_FIRST_**.
4. Launch Minecraft.
4. Enjoy controlling Minecraft with your calculator.
